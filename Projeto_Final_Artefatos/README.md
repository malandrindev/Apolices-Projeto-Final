# Artefatos finais — InsurMinds

Entrega acadêmica do projeto I2A2: relatório técnico PDF, Pitch Deck e vídeo oficial de até cinco minutos. A fonte editável do relatório está em `docs/InsurMinds_Relatorio_Tecnico.md`. O ZIP local da entrega chama-se `InsurMinds_Projeto_Final.zip`.

O vídeo mostra a execução E2E real registrada sobre dois recortes de quatro páginas (Allianz nativo e Porto com OCR Tesseract). Não representa validação integral ou precisão comercial. A demonstração offline da aplicação usa especificações fictícias identificadas e excertos documentais.

`source/` contém a gravação bruta local; `video_versions/` guarda as duas alternativas de vídeo para escolha do grupo. Gravação bruta, intermediários e vídeos alternativos não acompanham o Git público; o roteiro pode ser versionado. A versão obrigatória é `InsurMinds_Projeto_Final.mp4`.

`EVIDENCE_BUNDLE.json` preserva evidência histórica sintética anterior; não deve ser confundido com a execução real final. As evidências finais e a seleção de vídeo constam de `docs/FINAL_DELIVERY_VALIDATION.md`.
