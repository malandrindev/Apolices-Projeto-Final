# Requisitos do Projeto Final

## MVP obrigatório

- receber documentos em PDF ou imagem;
- extrair informações relevantes automaticamente;
- estruturar e armazenar os dados;
- permitir consulta das informações;
- comparar ao menos duas apólices;
- apresentar as principais diferenças;
- usar ao menos um modelo de IA generativa;
- oferecer uma interface demonstrável.

OCR é permitido e recomendado quando necessário, mas não é obrigatório se a
extração escolhida atender aos documentos do escopo.

## Entregáveis

- relatório técnico em PDF com arquitetura, tecnologias, agentes, fluxo,
  justificativas, limitações e evoluções futuras;
- link para repositório público;
- ZIP com código e artefatos;
- `Projeto_Final_Artefatos/InsurMinds_Projeto_Final.pptx`;
- `Projeto_Final_Artefatos/InsurMinds_Projeto_Final.mp4`, com até 5 minutos.

Prazo: **06/10/2026 às 23h59**.

Fonte: `Desafios.pdf`, páginas impressas 20–25. O PDF original permanece fora
deste repositório; este documento registra apenas o escopo operacional.
