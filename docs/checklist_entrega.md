# Checklist de entrega

## Produto

- [ ] Lê PDF ou imagem.
- [ ] Extrai e estrutura informações automaticamente.
- [ ] Compara pelo menos duas apólices.
- [ ] Exibe diferenças principais e evidências de origem.
- [ ] Usa IA generativa.
- [ ] Possui interface demonstrável.
- [ ] Fluxo ponta a ponta foi testado.

## Documentação e artefatos

- [ ] README contém descrição, instalação, execução, tecnologias e integrantes.
- [ ] Licença MIT está presente.
- [ ] Relatório técnico em PDF está concluído.
- [ ] Repositório está público e sem segredos ou dados pessoais.
- [ ] ZIP final foi validado em ambiente limpo.
- [ ] `InsurMinds_Projeto_Final.pptx` está na pasta obrigatória.
- [ ] `InsurMinds_Projeto_Final.mp4` tem no máximo 5 minutos.
- [ ] E-mail de entrega está preparado para o representante e a equipe em cópia.
